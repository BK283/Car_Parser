# 🚗 Kolesa.kz Parser

Парсер новых автомобилей с сайта [kolesa.kz](https://kolesa.kz) с фильтрацией по цене и городу.  
Проект создан для автоматизации сбора данных о новых автомобилях в Казахстане.  

---

## 📋 Описание

Парсер собирает информацию о новых автомобилях:

- Марка и модель 🏎️  
- Цена 💰  
- Технические характеристики 🛠️  
- Ссылки на объявления 🔗  
- Поддержка множественных страниц ↔️  

Данные сохраняются в **текстовый файл `list_cars.txt`** 📄  

---

## 🛠 Технологии

- **Python 3.8+** 🐍  
- **Selenium** - автоматизация браузера 🌐  
- **BeautifulSoup4** - парсинг HTML 🔍
